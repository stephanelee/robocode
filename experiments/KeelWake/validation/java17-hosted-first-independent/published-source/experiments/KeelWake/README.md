# KeelWake (unmeasured experimental derivative)

KeelWake0.1.0 starts from immutable original Keel0.1.0 at24fb9a5. It changes only the timing of selected in-flight wave density estimates: a new matched incoming-hit/collision label makes the first two planning waves eligible for a lazy refresh through the unchanged estimator. The fire-time features, estimator parameters, firing/gun/radar policy, RAM correction, STOP rollout, physics and disabled shadows remain original Keel. No Helm or Brace treatment is inherited.

The four round-local telemetry counters are matchedDangerLabels, refreshEligiblePlans, refreshedWaves and densityChangedWaves. Each is capped at1,000,000; the first attempted exceed emits diagnosticOverflow and throws, invalidating acquisition. Same-epoch planning adds no estimator evaluation; at most two distinct selected waves refresh per plan. Density changes greater than1e-12 are counted, not used to suppress smaller updates.

Build/test with the repository's pinned Temurin17.0.21+9 workflow. No local alternate JDK or gameplay fixture supplies competitive evidence. `test/FrozenKeelSurfer.java` is the original production Surfer with only its class declaration renamed, recorded in test-baseline-source.json, for a no-engine behavioral contrast. The unchanged shared Phys/Track/Knn sources execute both planners. Tests exercise actual matching and planner/cache wiring, not an independent arithmetic reimplementation.
