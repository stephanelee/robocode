# Independent shadow geometry oracle

This bounded mathematical diagnostic uses only the official pinned Tank Royale server binary and independently constructed segments. It does not launch bots or matches and has no Diamond input.

`ShadowOracle.java` calls the actual compiled official `MathKt.isLineIntersectingLine` and reflects the compiled `CollisionDetector.isBulletsMaxBoundingCirclesColliding` predicate. For a precise incoming origin, origin time and power it constructs the actual incoming bullet's one-tick radial segment at each sampled angle. The oracle is the conjunction of those two engine predicates. The independently derived analytic candidate clips the own segment to the corresponding radial annulus, maps the supported subsegments to circular angular intervals, and intersects those intervals with the engine endpoint broad-phase angular cap. It erodes interval endpoints inward by1e-9 radians to avoid assigning safety credit to numerically ambiguous tangent edges.

Each case samples65536 deterministic angles around the whole circle plus all derived arc endpoints/midpoints and fixed edge probes. Every credited sample must satisfy the actual compiled engine collision predicate. Missing credit is permitted and reported; false credit fails. Unconfirmed own requests, origin/time/power uncertainty, wrong ticks and death at or before shadow tick supply no guaranteed intervals. Cases cover partial annulus clipping, disjoint radial ranges, wrapping angles, temporal mismatch, endpoint broad-phase rejection (an intentionally overlong/stale segment robustness fixture), death before/at tick, pending own fire and uncertain incoming origin/time/power. The overlong segment is explicitly not a legal single-turn bullet displacement.

This verifies bounded fixtures and sampled angular inclusion against the exact engine predicate, not universal formal correctness, live bullet identity/lifecycle delivery, or battle strength. The candidate's analytical clipping proof is separate from sampled runtime validation. No shadow coverage is inferred from arbitrary endpoint-only radial overlap.
