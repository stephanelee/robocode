# Reference experiment — 2 November 2026

This is an integration baseline, not evidence that DQN improves playing strength. The three evaluation policies won every round against this small sample roster, so it does not discriminate their strength. The trained policy also produced more wall collisions in several scenarios.

## What the baseline establishes

The source builds, bots boot headlessly, actual matches finish, training creates valid checkpoints, frozen evaluation loads them, and telemetry joins official results. This is sufficient to establish the benchmark pipeline works.

The standalone dashboard was regenerated from this canonical JSON and checked with automated report/security tests. Browser visual inspection could not be completed because the computer-use URL policy blocked opening the local HTML file.

Five rounds per policy, one bot seed, unpaired random starting positions, and easy sample opponents are insufficient to attribute score differences to learning. Trained DQN's 59 wall collisions against Walls and 32 in melee expose movement weaknesses despite winning these rounds. A stronger opponent roster, larger repeated evaluation budgets, multiple bot seeds, and uncertainty estimates are needed before making competitive-strength claims or expanding the model.
