# First offline residual model: prospective lock

Reviewed before real fitting. This tool uses the accepted legal-scan schema, history8 and fixed horizons8/16/24/32/40. Acquisition remains the separate45-round pilot. No live controller changes or strength claims follow from an offline pass.

One ridge model per horizon predicts two coordinate residuals relative to current constant-turn projection. Alpha is exactly10 with an unpenalized intercept. Train-only population means/scales standardize24features; zero-variance scales become1. No hyperparameter search, iterative training or feature selection. All eligible observed train labels are used once in sufficient statistics. Dev selects only one comparison/fallback baseline, by equal-game mean radial displacement error averaged equally over24/32/40; ties follow headon,linear,circular,current order. No held-out labels participate in fitting or selection.

The exact ordered features are target-minus-own x/y; target Cartesian vx/vy; last-two-distinct-scan direction change normalized to[-180,180) divided by observed-turn gap; speed acceleration over that gap; scan age; range; target left/right/bottom/top distances from the legal radius18 boundary; own vx/vy; previous requested target speed and body turn rate (missing0), plus their two presence flags; latest confirmed own-shot age capped40 (absent40), latest power(absent0), deduplicated shot count and presence; present-frame fraction; distinct observed-scan count. Shots are deduplicated by bullet ID only within the eight-frame history, after schema validation. No IDs, current intent, label availability or private opponent state is a learned input. Missing previous scan gives zero turn rate/acceleration. Learned eligibility requires scan age<=2 and at least2 distinct scans; otherwise the frozen dev-selected baseline is returned. Full observed-label metrics include this fallback; eligible-only error/containment and counts are also reported.

Headon returns the cached target position. Linear advances constant velocity by scanAge+h. Circular uses the accepted analytic constant-turn integration for scanAge+h, continuous into linear at abs(omega)<1e-8 radians. Current uses the same circular coordinates, finally clamped to[18,width-18] and[18,height-18]. These are fixed-horizon forecast comparisons, not an assertion of exact bullet-interception equivalence. The learned residual is not clipped after prediction. All methods use identical exact-fresh-label masks. Virtual containment means Euclidean predicted-position error<=18 pixels; it is a proxy, not engine bullet intersection or hit rate.

Fit stage writes model/preprocessing/source/input hashes and a dev-only report. Publish/freeze that JSON hash before the single withheld/transfer evaluation; evaluation requires the exact model SHA and matching tool/manifest/events hashes. Use a new output directory each time. No outcomes are inspected for retuning. Correlated anchors are summarized per game/horizon, never treated as independent trials.

Offline gates use unrounded values and equal-game/equal-horizon means. Each of3 withheld Retcon games needs at least50 fresh observed labels at each primary horizon24/32/40; every withheld/transfer game needs some labels at every horizon. Insufficient coverage is inconclusive, with no replacement games. Withheld primary mean error must be<=90% of the selected baseline; at least2/3 games strictly improve; worst game error<=1.10baseline; each game's mean short-horizon8/16 error<=1.10baseline; equal-game primary containment gain>=2percentage points. For each of3 transfer games, primary containment loss<=2points and error increase<=5pixels. Any failed gate rejects this offline candidate. No live promotion is authorized by this test; a later gun-only A/B needs its own reviewed protocol.
