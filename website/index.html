The rules of engagement

Confirmed tournament format
01 / MATCH FORMAT

Two games. One result.

Each pairing plays two games of 20 battle rounds. Launch order reverses in game two. Combined official score decides the pairing winner.

02 / POINTS

Win 3. Draw 1. Lose 0.

Exact combined-score ties earn one point each in Swiss play. Practice earns no points. Swiss points reset when playoffs begin.

03 / SWISS

Four chances before the cut.

All bots play four rounds, paired by similar points without repeat opponents. Rank by points, then opponents’ points, then average pairing score share.

04 / PLAYOFFS

A second path to the final.

Top eight qualify: 1v8, 4v5, 2v7, 3v6. Two playoff pairing losses eliminate a bot. The grand final resets if the lower-bracket bot wins.

05 / TIES & FAILURES

Every outcome stays visible.

Playoff ties use round wins, then one extra 20-round game, then documented lots. Incomplete games remain unscored; failures are retained and never silently replaced.

06 / FAIR STARTS

Fresh models. Fixed entries.

Reset learning between games; allow normal learning within a game. Freeze bot sources and binaries. Run sequentially on minimind with the pinned Tank Royale 1.4.0 engine.
