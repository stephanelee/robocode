[Pinned Ubuntu template](https://github.com/actions/runner-images/blob/9df30d63b790ea2057d1f50295a8f8a9a303bd88/images/ubuntu/templates/build.ubuntu-26_04.pkr.hcl) passes the same `var.image_version` as IMAGE_VERSION to both metadata and environment generation. 3. These are environment metadata, not a measured VM content digest.

[Pinned runner JobExtension](https://github.com/actions/runner/blob/d1eb12d4b115c301201de27d667284e1a80f2ab5/src/Runner.Worker/JobExtension.cs) prints noninternal group/detail records loaded from its setup-info file.
