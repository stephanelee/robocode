## Fixed bounded schema and lifecycle

DefaultOFF `CHALLENGER_DIAGNOSTIC_PATH`; logger output and status sidecar disjoint from policy state. No record enters any controller input or learning update. Buffered JSONL at most60000records/32MiBTOTAL, per-round shot join map at most4096, closed-round calls ignored inside logger only. Boundary-only flush occurs after terminal pending wave-hit inference, before normal model/metrics serialization; status records cumulative stored records/bytes/drops/failure and completed rounds. Logging may change runtime overhead; skips and truncation must be disclosed. No3x90path dumps or duplicated model snapshots per tick.

Each row has `type,round,turn`; turns use original event/decision keys, never cross-JVM clock subtraction.

- `shot`: confirmed API shotId, creation turn, decisionTurn, actual origin/power/direction; frozen requested aimDirection/model/learned, decisionGunDirection, ownState[x,y,bodyHeading,speed]/energy/heat; query7features/linearGF/predictedGF/support/kthDistance/escape/referenceBearing/sign. These are center-passage proxies, not bullet-body collision truth. No future label becomes a controller input through the logger.
- `virtual`: completed old3model rays, creationTurn/shotId/model/hit; requested virtual ray differs from actual fired direction and must not be called actual hit. `hit`: actual API bulletId as shotId, victimId/damage/turn. `removal`: actual bullet-bullet collision.
