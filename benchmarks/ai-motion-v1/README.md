# First real supervised motion pilot — rejected

[PR #28](https://github.com/stephanelee/robocode/pull/28) / [full report and prospective protocol](../../docs/ai-motion-pilot.md).

All **45 rounds in 15 fresh games** validated, producing **26,962 legal pre-decision records**. The fixed ridge predictor was fitted on six Retcon training games; development selected head-on as the comparison baseline. The frozen model was published before one withheld/transfer evaluation. **Reject: no live AI predictor is enabled.** Mean position error improved against the current motion projection but missed the best simple baseline and sharply reduced radius-18 containment. That containment is an offline proxy, not an actual hit rate.
